# ToDo app

`todo-app/` is the brownfield FastAPI app you build on across the labs. The repo-root `CLAUDE.md` covers the AndThen workflow; this app's `README.md` covers how to run it and the test command.

Project-specific guidelines – tech stack, architecture, coding conventions – are deliberately not pre-written here. Running `/andthen:init` scaffolds them (a `docs/guidelines/` set, a `STACK.md`, and a per-app file) when you want that structure: structure is a dial you turn, not a fixture you inherit.
