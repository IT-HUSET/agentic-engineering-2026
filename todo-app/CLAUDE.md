# ToDo app

`todo-app/` is the brownfield FastAPI app you build on across the labs. The repo-root `CLAUDE.md` covers the AndThen workflow; this app's `README.md` covers how to run it and the test command.

Project-specific guidelines – tech stack, architecture, coding conventions – are deliberately not pre-written here. Running `/andthen:init` adds the project document Index and key development commands, then offers more (role agents, critical rules, `describe`, project documents) when you want that structure: structure is sized to the work, not a fixture you inherit.
